## POST uploadFile

POST /file

上传文件，返回文件消息

> Body 请求参数

```yaml
bizType: CHAT

```

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|bizType|query|string| 是 | KNOWLEDGE :知识库中上传的文件，CHAT：聊天中上传的文件 |
|Authorization|header|string| 否 |none|
|body|body|object| 否 |none|
|» files|body|string(binary)| 是 |none|
|» bizType|body|string| 是 |none|

#### 详细说明

**bizType**:  KNOWLEDGE :KNOWLEDGE
CHAT :CHAT

            "createTime": null,

# KnowledgeController

## POST fileInsertKnowledge

POST /knowledge/file

将文件上传到指定知识库

> Body 请求参数

```json
{
  "fileIds": [
    0  // 文件ID列表
  ],
  "knowledgeId": 0 // 知识库ID
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|Authorization|header|string| 否 |none|
|body|body|[KnowledgeFileDTO](#schemaknowledgefiledto)| 否 |none|

> 返回示例

> 200 Response

```json
{
    "code": 1,
    "msg": "文件ID不能为空！",
    "data": null,
    "total": null
}
```
```json
{
    "code": 0,
    "msg": "ok",
    "data": "上传中~",
    "total": null
}
```

|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|[Result](#schemaresult)|

# 数据模型

<h2 id="tocS_Result">Result</h2>

```json
{
  "code": 0,
  "msg": "string",
  "data": {},
  "total": 0
}

```

### 属性

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|code|integer|false|none||0成功，其他失败|
|msg|string|false|none||提示信息|
|data|object|false|none||成功时的数据|
|total|integer(int64)|false|none||none|
